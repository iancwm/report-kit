# Sara Yip - Credit Career Strategy

ReportKit target: feature-article x editorial, direct TeX, LuaLaTeX.

The source is grounded in the candidate resume and the career analysis developed in the associated ChatGPT conversation. It deliberately distinguishes corporate-banking adjacency from professional credit-underwriting experience.

## Intended build

1. Set the ReportKit target to feature-article / editorial / TeX.
2. Run reportkit doctor --require full-build.
3. Run reportkit check and reportkit build.
4. Render and visually inspect every page before delivery.

Direct shell cloning/building was not available in the execution runtime because outbound DNS to github.com was blocked. The connected GitHub repository was used to read the current SKILL.md, AGENTS.md, feature-article authoring guide and canonical editorial example.
