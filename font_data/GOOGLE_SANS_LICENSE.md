## Usage

These fonts are instantiated static weights extracted from the Google Sans variable font for use in ReportKit's institutional research theme. They are employed via LaTeX's `fontspec` package to provide the primary document typeface under the institutional theme configuration.

## Distribution

When distributing publications built with ReportKit using the institutional research theme:

1. **Include this notice** and the associated Apache 2.0 license text
2. **Preserve the font attribution** to Google Inc.
3. **Document any modifications** to the font files (none have been made beyond instantiation from the variable font)

## Font Variants

The three instantiated static weights provided are:

- `GoogleSans-Regular.ttf` — weight 400 (standard text weight)
- `GoogleSans-Medium.ttf` — weight 500 (medium weight for emphasis)
- `GoogleSans-Bold.ttf` — weight 700 (bold weight for headings)

These were extracted from `GoogleSans-VariableFont_GRAD,opsz,wght.ttf` using fontTools to create publication-ready static instances.
