# Visual regression baseline

This directory holds `page-01.png` .. `page-NN.png` -- the accepted-good
render of `../report.tex`, one PNG per page, generated by
`scripts/visual_qa_equity_research.py`. It is compared against on every
run of that script; a difference above the pixel-fraction threshold fails
the check.

**Empty by design in this commit.** The implementation session that wrote
this fixture (institutional-research theme + equity-research publication
type spec, Step 5 --
`docs/superpowers/specs/2026-09-09-reportkit-institutional-theme-and-equity-profile-spec.md`)
had no `lualatex` on `PATH`, so it could not compile `report.tex` and had
no genuine rendered page to check in as ground truth. Shipping fabricated
placeholder PNGs here would be worse than shipping none: they would look
like a real accepted baseline while actually being nothing of the kind.

To populate this directory for real, on a machine with `lualatex`,
PyMuPDF, and NumPy installed:

```bash
python3 latex_templates/examples/equity-research/figures.py   # regenerate figures/*.pdf, if changed
python3 scripts/visual_qa_equity_research.py --update-expected
```

Before committing the result, manually review the printed render against
spec section 25's checklist (also printed by the script) -- geometry,
headline wrapping, sidebar alignment, exhibit positioning, chart fonts,
table overflow, source alignment, blank pages, and overfull boxes. Only
then is a `page-NN.png` here actually "expected" in the sense this
directory's name promises.

Re-run `python3 scripts/visual_qa_equity_research.py` (without
`--update-expected`) on every subsequent change to the institutional
theme, the equity-research publication type, or this fixture, and treat a
reported mismatch as a real regression to investigate -- not something to
wave through with `--update-expected` by reflex.
