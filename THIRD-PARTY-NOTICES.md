# Third-party notices

This file records material whose terms are separate from ReportKit's source
and original publication content.

| Material | Use | Licence / terms | Source or notice |
|---|---|---|---|
| Libertinus font subset in `font_data/reportkit-libertinus-fonts.tar.gz` | Report typography | SIL Open Font Licence 1.1 | Upstream Libertinus project; preserve its licence and font notices |
| Google Sans fonts in `font_data/GoogleSans-*.ttf` | Institutional research theme typography | Apache License 2.0 | Google Fonts; see `font_data/GOOGLE_SANS_LICENSE.md` |
| `font_data/LinBiolinum_K.otf` stub | LuaLaTeX font fallback | See the accompanying stub README and upstream font terms | `font_data/LinBiolinum_K_stub_README.md` |
| TeX Live packages | PDF build dependencies | Each package's upstream licence | Installed TeX distribution |
| Python packages used by analytical figures or PDF inspection | Build dependencies | Each package's upstream licence | The relevant requirements file |
| User-supplied datasets, images, and templates | Publication inputs | The contributor's stated terms | Record a source and licence beside each asset |

The table is intentionally conservative. Adding an asset requires its source,
licence, attribution text, and any redistribution conditions to be recorded
before it is included in a generated publication.
